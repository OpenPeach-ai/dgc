How it was scored

Each harness received the same task checkout and the same endpoint. The project’s unmodified test command graded each submitted patch in isolation. A task counts at {{BENCH_FIRST_METRIC}} if the first round passes. After a failure, the final recovery round continues the same session with a bounded failure tail; this {{BENCH_PUBLICATION_LABEL}} calls a task {{BENCH_METRIC}} when it passes by the end of that separately timed recovery round.

The comparison is a {{BENCH_PUBLICATION_LABEL}} of {{BENCH_PROBLEMS}} tasks, not DGC’s stricter publication gate: Aider is absent, the run contains {{BENCH_PROBLEMS}} rather than {{BENCH_GATE_PROBLEMS}} tasks, and {{BENCH_RUNNER_CLAUSE}} in the manifests. Those limitations are preserved here because evidence is more useful than a cleaner story.

Why there is no completion-profile curve

The saved runner grants {{BENCH_CAP_SECONDS}} seconds to each round. A {{BENCH_METRIC}} curve ending at {{BENCH_CAP_SECONDS}} seconds per problem would therefore be false. We are holding FIG.4b back until a new league run uses one shared per-problem deadline.
