# DGC

A coding agent for the models **you** run — Ollama, llama.cpp, vLLM, or any OpenAI-compatible endpoint.

- Streaming responses with a live thinking indicator
- Tool calls, inline diffs, permission prompts
- Native menus for model, provider, mode, and thinking level

Open the **DGC** panel from the activity bar and start with a prompt like *"add a test for auth.py"*.
