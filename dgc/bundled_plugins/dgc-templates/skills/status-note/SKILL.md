# Status note

Write a short status the reader can scan. Use these sections, in this order, and omit a section that has nothing to say:

1. **Now** — one sentence on where the work stands.
2. **Done** — the few changes that landed, each as a single line.
3. **Next** — the next concrete step, with who does it if that is known.
4. **Blocked** — what is waiting, and on whom. If nothing is blocked, write "None."

Keep it under a page. Do not invent dates, owners, or metrics. If a number was not given, leave it out. Use Markdown headings and a short list. Do not wrap the note in a slide deck or a spreadsheet.
