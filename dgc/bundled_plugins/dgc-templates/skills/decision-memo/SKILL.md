# Decision memo

Write a decision record in Markdown with these sections:

1. **Decision** — the choice, in one or two sentences.
2. **Why** — the reasons that actually decided it. Prefer the user's reasons over new ones.
3. **Options set aside** — each alternative in one line, with the reason it lost.
4. **What changes** — what someone should do differently because of this decision.
5. **Open** — questions still unanswered. Write "None" if the decision is closed.

Do not add a legal opinion, a financial model, or a slide outline unless the user asks for one. If the user has not chosen yet, label the piece "Recommendation" instead of "Decision" and say so in the first line.
