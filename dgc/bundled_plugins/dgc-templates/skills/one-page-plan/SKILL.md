# One-page plan

Write one Markdown page:

1. **Goal** — the outcome, not the activity.
2. **Done when** — the checks that show the goal is met.
3. **Steps** — ordered, each step small enough to start. Name a dependency when one step cannot start before another.
4. **Risks** — what could make a step fail, and the response if it does.
5. **Out of scope** — nearby work this plan does not cover.

Stop at one page. Do not expand a step into a design document. Ask only if a missing fact would change the order of the steps.
