# Simple letter

Write the message as the user would send it.

- Start with the greeting they would use. If they did not name one, use a neutral "Hello."
- Put the ask or the news in the first paragraph.
- Add only the facts they supplied.
- Close with the next step, then their name if they gave it.

Do not add a letterhead, a logo, or a legal footer. Do not soften a direct request into a marketing paragraph. If the audience or the ask is missing, ask once, then draft.
