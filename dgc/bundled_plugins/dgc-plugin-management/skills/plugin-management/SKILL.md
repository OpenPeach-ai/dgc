# Plugin management

DGC plugins are installed from DGC Settings, on the Plugins page. A plugin can contain instruction skills and, for some entries, a remote MCP server.

## Choose what is already available

Use a built-in tool when it can do the task. Use an installed plugin's skill or MCP tool when that plugin is already connected. Do not tell the user to install something that is already connected.

## When a plugin would help

Say which plugin and what it adds. The user installs it from Plugins. A browser plugin then shows a sign-in notice with Open link and Cancel. Do not claim the browser opened, or that the plugin is connected, until the row says Connected.

If a server refuses DGC's sign-in client, say that plainly. Do not invent a login link.

## Skills

Each plugin page lists its skills. A skill that is switched off must not be followed. Do not re-enable a skill the user turned off unless they ask.

## Removal

Do not delete a plugin's files unless the user asks to remove that plugin.
