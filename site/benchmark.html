How it was scored

Each harness received the same task checkout and the same endpoint. The project’s unmodified test command graded each submitted patch in isolation. A task counts at pass@1 if the first round passes. After a failure, the final recovery round continues the same session with a bounded failure tail; this measured slice calls a task pass@2 when it passes by the end of that separately timed recovery round.

The comparison is a measured slice of 90 tasks, not DGC’s stricter publication gate: Aider is absent, the run contains 90 rather than 225 tasks, and its runner commit was not recorded in the manifests. Those limitations are preserved here because evidence is more useful than a cleaner story.

Why there is no completion-profile curve

The saved runner grants 600 seconds to each round. A pass@2 curve ending at 600 seconds per problem would therefore be false. We are holding FIG.4b back until a new league run uses one shared per-problem deadline.

04 Reproduce

Run the same slice.

The saved manifest did not record its runner revision, so exact byte-for-byte recreation is not possible. This recipe uses the latest public runner on main with the pinned dataset, declared model digest, context and time limits; record and pin the DGC commit for your own stable rerun. Confirm the endpoint’s model digest separately because the runner records that value but does not verify the weights.

shell · reproduction
$ git clone https://github.com/OpenPeach-ai/dgc && cd dgc
$ git rev-parse HEAD # record this; checkout it on every rerun
$ python3 -m venv .venv && .venv/bin/pip install -r requirements.lock
$ .venv/bin/pip install --no-deps -e .
$ git clone https://github.com/Aider-AI/polyglot-benchmark.git bench/data/polyglot-benchmark
$ git -C bench/data/polyglot-benchmark checkout 7e0611e77b54e2dea774cdc0aa00cf9f7ed6144f
$ bash bench/install_harnesses.sh
$ PATH="$PWD/.venv/bin:$PATH" .venv/bin/python bench/run_bench.py \
    --engine dgc --model qwen3.8:27b-orig --model-digest sha256-a448bc634a972fb6d18e01b89d443e1f3628921a7d0dbc5f2541f7d32190418b \
    --base-url http://localhost:11434/v1 --context-size 32768 --limit 15 \
    --rounds 2 --dgc-timeout 600 --test-timeout 400 \
    --out bench/results/reproduction
