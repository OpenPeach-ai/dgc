08 Focus pane

Keep working while it works.

A second surface under the transcript. Open the file explorer, browse and pick files for the next prompt, watch the model’s edits land—the agent never stops streaming above it. And a measured estimate of when the turn will finish, so you can walk away.

/files · a file explorer in the loop

Three columns, previews, copy/cut/paste, rename, trash with undo. Enter drops @path into your prompt; files the model changed this turn carry a mark.

Turn ETA · know when to come back

A range, not a promise: ~2–4 min left with the task count beside it, from this project’s own history and the turn’s task list. /eta stats reports how often it held.

/notify · walk away

A terminal notification, an editor toast, or your Stop hook when the turn ends. Your choice.

Native routes, real safety

Writes follow the permission mode and stay inside the project; nothing enters the model’s context unless you insert it. No shell, ever.

09 Live diff

See every change as it lands.

/diff opens a live view of everything the model has changed—every file with its added and removed line counts, and the diff itself—under the transcript while the turn keeps running. Select the lines you want to talk about and press Enter: they land in your next prompt as a quoted diff, so “why did you change these two lines?” quotes exactly those two lines.

/diff · what changed, live

Git’s own answer, read-only: the working tree against HEAD, staged and untracked files, +12 −3 per file, the whole set summed in the header. Re-read every two seconds while it is open, so edits appear as they land.

Select lines → your prompt

Space starts a selection, Enter attaches it as a fenced diff block with the file and line range; a takes the whole hunk. Nothing else about the file enters the model’s context.

Side by side, or one at a time

Wide terminals show the file list and the diff together; narrow ones swap between them with Tab. J / K step through files without leaving the diff.

Looking, not committing

It never writes, stages or runs a shell command. Approving or undoing a turn stays with /review and the editor’s Changes view; /diff is for looking and asking while the work is still moving.
