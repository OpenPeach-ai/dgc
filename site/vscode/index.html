Extension 0.24.0

Editor protocol v13; requires DGC CLI 0.39.0. Adds background monitors, token usage reports and resuming a turn the backend was interrupted in.

  • Tasks become a row in the bar above the prompt, like the goal: collapsed to Tasks 2/5 with the step in progress, expandable to the full list, remembered per chat, and Clear works while a turn runs.
  • A running command is shown once, on its card; the group header and the activity row no longer repeat it.
  • Settings → Token Usage shows input, output and cached tokens by model and by day, counted on this machine.
  • Background monitors: each event is a card in the transcript, running monitors sit in a row above the prompt with a Stop button, and a turn a monitor started is marked as such, never as something you typed.
  • When the backend exits, the panel says why and offers Continue; a model request that has gone quiet shows as waiting on the activity row; queued messages survive slash commands and the restart DGC holds until a turn ends.
  • Cmd/Ctrl+Z in the prompt box brings back a message you just sent or text you deleted, and the prompt box keeps its size when you come back to DGC from another view.
  • The editor tabs and activity bar show the DGC mark instead of a terminal glyph, and an automatic CLI update runs in the installation it belongs to.
  • Chat history rebuilt after a restart, a reload or a resume keeps its spacing; queued messages are drawn once and in order, and Stop hands them back as not sent instead of dropping them; the view no longer jumps after the panel is resized.
  • Undo in the prompt box works on whole typing runs, drafts keep pasted-text chips across a reload, /usage opens Token Usage, and the screenshot viewer keeps keyboard focus until it closes.
  • An image attached by @-mention, drag or Add File to Chat reaches the model as pixels, and the Update CLI terminal stays open with the installer's output.
